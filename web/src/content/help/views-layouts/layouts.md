Each list can be displayed two ways — switch with the layout control above the list:

- **Grid** — a responsive card grid with a column count you choose (2–5). Cards flow to fit the window and collapse to a single column on phones.
- **Kanban** — categories become side-by-side columns in a horizontal carousel, and you drag cards between columns to recategorise them.

![A list in kanban layout — each category is a column](/help-images/kanban.png)

The choice — including the grid column count — is remembered **per list**, so your dense reference list can be a 5-column grid while your project board stays kanban.
