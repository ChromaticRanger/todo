Click **Add → Note** (or press **Alt+N**) for free-form text. Notes support full **Markdown**:

- Headings, **bold**, *italic*
- Bullet and numbered lists
- Code blocks and inline code
- Links (bare URLs are auto-linked) and embedded images

Rendering is safe — raw HTML in a note is shown as text, never executed, and links always open in a new tab.

Notes are ideal for reference material that lives alongside a project's tasks: meeting notes, checklists-in-prose, snippets, addresses.
