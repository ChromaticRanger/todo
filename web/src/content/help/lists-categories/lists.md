Lists are the top level of organisation — each one is a tab across the top of the app.

- **Create** — click **+ New list** in the tab bar. On the Free plan you can have up to 3 lists; Pro is unlimited.
- **Rename** — a list's name can be changed at any time; items stay put.
- **Reorder** — drag the tabs into whatever order suits you.
- **Delete** — removes the list *and everything in it*, so you'll be asked to confirm.

Each list remembers its own layout preferences (grid or kanban, column count) — see *Views & Layouts*.
