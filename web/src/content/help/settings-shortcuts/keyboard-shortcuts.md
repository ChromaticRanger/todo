summary: The full list of quick keys.
plan: free

---
| Shortcut | Action |
|---|---|
| **Alt+T** | New todo |
| **Alt+B** | New bookmark |
| **Alt+N** | New note |
| **Ctrl/⌘K** | Global search (Pro) |
| **Esc** | Close any open dialog |
| **Enter** | Confirm / submit in dialogs |

Shortcuts work anywhere in the app except while you're typing in a text field (Esc always works).
