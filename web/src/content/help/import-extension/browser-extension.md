The **Stash Squirrel Chrome extension** (free, on the Chrome Web Store) captures things without opening the app: save the page you're reading as a bookmark, or jot a todo the moment it occurs to you, straight into the list and category you choose.

To set it up:

1. Install the extension from the Chrome Web Store.
2. Click **Connect** in the extension pop-up — it opens Stash Squirrel, which mints a secure session token for the extension. You'll see the connection reflected in **Settings → Browser extension**.
3. That's it — the pop-up now shows your lists and saves directly into them.

You can disconnect the extension from Settings at any time.
