The **Stash Squirrel Chrome extension** (free, on the Chrome Web Store) saves the page you're reading as a bookmark, straight into the list and category you choose, without opening the app. It fills in the page title for you, and you can add a description before saving.

To set it up:

1. Install the extension from the Chrome Web Store.
2. Click **Connect** in the extension pop-up — it opens Stash Squirrel, which mints a secure session token for the extension. You'll see the connection reflected in **Settings → Browser extension**.
3. That's it — the pop-up now shows your lists and saves directly into them.

You can disconnect the extension from Settings at any time.

The extension saves **bookmarks** only. Todos, notes and events are created in the app itself — see *Creating and editing todos*.
