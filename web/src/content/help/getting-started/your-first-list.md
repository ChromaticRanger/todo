Everything you save lives in a **list**. Click **+ New list** in the tab bar to create one, give it a name, and it appears as a tab.

![A list with bookmarks, a todo and a note grouped into categories](/help-images/app-overview.png)

To add items, use the **Add** button in the header and pick a type:

- **Todo** (Alt+T) — a task you can complete
- **Bookmark** (Alt+B) — a saved URL
- **Note** (Alt+N) — free-form markdown text
- **Event** (Pro) — a calendar entry with a start time

![The Add menu with its keyboard shortcuts](/help-images/add-menu.png)

Each item goes into the list you're viewing and can be given a **category** — a group heading within the list. Type a new category name when adding an item and it's created on the spot.
