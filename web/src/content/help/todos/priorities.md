title: Priorities

---
Every todo has a priority: **Low**, **Medium** or **High**. Set it when creating the todo or later via Edit.

Priority shows as a coloured stripe on the todo's card — green for Low, blue for Medium, red for High — so a scan down a list is enough to see what matters most.
